# MC-SimpleGames

A simple Minecraft Bedrock add-on that introduces two lightweight casino-style games using random number generation.

## Features

This add-on currently includes two games:

### 🎲 Number Guessing Game
A simple guessing game where players try to predict the randomly generated number chosen by the system.

Players can choose between:
- **Single Number Guess** — Pick one number and test your luck.
- **Double Number Guess** — Guess two numbers for a higher potential reward.

The game uses random selection mechanics to determine the outcome.

### 📈 Hi-Lo Game
A classic high-low guessing game.

Players are given a starting number and must predict whether the next generated number will be:
- **Higher**
- **Lower**

Correct guesses result in a successful win, while incorrect guesses result in a loss.

## About

This project was created as a simple and easy-to-understand example of implementing random-based games in Minecraft Bedrock scripting.

The goal of this add-on is not to create a complex casino system, but rather to provide fun, lightweight games that can be easily integrated into a server environment.

## Requirements

- Minecraft Bedrock Edition
- Script API support enabled
